# A_Proyecto: Sistema de Citas Académicas UNIANDES

## Clasificación del proyecto

| Campo | Respuesta | Evidencia/Razón |
|---|---|---|
| Tipo de proyecto | Desarrollo nuevo | Se creará un sistema desde cero para gestionar citas académicas entre estudiantes y docentes, reemplazando procesos manuales. |
| Stakeholders clave | Estudiantes, docentes, administrador académico y soporte tecnológico | Los estudiantes necesitan solicitar citas, los docentes administrar horarios y los administradores controlar el funcionamiento del sistema. |
| Riesgo principal | Cambios frecuentes en los requisitos | Las necesidades académicas pueden modificarse durante el desarrollo, generando ajustes en funcionalidades. |
| Restricción principal | Tiempo de desarrollo | El sistema debe ser desarrollado y entregado dentro del periodo académico establecido. |
